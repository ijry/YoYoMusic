# 常见问题

## 播放相关

### 导入后没有声音

按顺序检查：

1. 底部播放条左侧是否显示了曲目信息，中间按钮是否处于「暂停」状态（表示正在播放）。
2. 音量是否为 0，或者是否处于静音。
3. Linux 上是否安装了 ALSA 运行库：`sudo apt-get install libasound2`。

### 某些文件显示「不可播放」

说明解码器无法解析该文件。可能是编码格式不受支持，或文件本身损坏。可先用其他播放器确认文件是否正常。

### 显示「文件丢失」怎么办

曲目被移动或删除后，列表里会保留条目并标记状态。移除该条目后重新导入即可。

## 界面相关

### 右侧功能栏不见了

右侧默认只显示一条图标栏，面板是收起的。点击任意图标即可展开，再点一次收起。

### 想隐藏播放列表

点击顶栏的「播放列表」按钮。收起后可视化会占满整个宽度。

### 可视化看起来在动但幅度很小

暂停状态下可视化会收敛成低幅度的呼吸线，这是刻意设计，避免暂停时画面完全死掉。开始播放后会恢复满幅律动。

### 换皮肤后配色没变

皮肤会同时驱动界面配色与可视化配色。如果只有部分元素没变，多半是当前面板还在使用旧的内联颜色，欢迎提 Issue。

## 数据与隐私

### 会上传我的音乐或听歌记录吗

不会。所有文件解析、标签读取和播放都在本机完成，程序不联网，也不需要登录。设置里的「联网补全」默认关闭。

### 设置存在哪里

设置、皮肤选择与窗口位置保存在本地应用数据目录，重启后自动恢复。

## 安装相关

### macOS 提示「无法验证开发者」

安装包未做代码签名。右键点击应用图标 → 选择「打开」，或在「系统设置 → 隐私与安全性」中允许。详见[安装](/guide/installation)。

### Windows 被 SmartScreen 拦截

点击「更多信息」→「仍要运行」。同样是未签名导致的。
