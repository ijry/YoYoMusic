# 功能总览

## 音频可视化

八种模式共用一套 Canvas 渲染管线，逐帧绘制。

**频谱来自真实音频。** 解码后的采样由 Rust 侧抽取、以约 30 次/秒送到界面，
界面做 FFT（Hann 窗 + 对数频段聚合）后驱动绘制。低频落在左边、高频落在右边，
低音鼓点会触发节拍响应——它跟着正在放的东西动。

| 模式 | 说明 |
| --- | --- |
| 频谱柱 | 镜像频谱条，带峰值保持标记与地面倒影 |
| 示波波形 | 发光示波曲线，叠加刻度网格与中心基准线 |
| 环形律动 | 环形放射律动，内核随低频脉动、整体缓慢旋转 |
| 音浪绸带 | 四层叠加的流动音浪，用加色混合叠出光带 |
| 粒子星尘 | 节拍驱动的粒子爆发，核心有脉动光环 |
| 镜像瀑布 | 滚动频谱瀑布，左半镜像到右半 |
| 生成动画 | 实时生成的星轨网络：节点各自沿椭圆漂移、就近连线，**每次运行都不一样** |
| 万花筒 | 频谱驱动的镜像花瓣，相邻扇区互为反射 |

切换方式有两种：舞台右上角的图标栏（快速切换），或右侧「可视化」面板（带名称与说明的完整列表）。

::: tip 暂停与浏览器预览
没有音频数据时（暂停、未载入曲目，或在浏览器里预览界面）会回退到一段合成的
「像音乐」的信号，而不是留一片空白——所以界面看起来始终是活的，但**只有播放时才是真实频谱**。
:::

::: tip 关于「实时」标记
播放且已载入曲目时，面板标题旁会出现「实时」徽标，表示当前显示的是真实频谱分析结果。
:::

### 最大化

舞台右上角图标栏最右侧有一个**展开**按钮（与模式图标之间用分隔线隔开）。
点击后可视化铺满整个界面成为底层，顶栏、左右面板与底部播放条以半透明玻璃浮在其上。
再点同一位置的按钮即可还原 —— 按钮不会移动位置。

## 皮肤

四套内置皮肤共享同一套现代布局，只切换配色 token —— 换皮肤不会改变任何操作位置。

| 皮肤 | 色调 |
| --- | --- |
| 极光玻璃 | 紫罗兰 → 青，默认皮肤 |
| 午夜霓虹 | 品红 → 蓝紫 |
| 落日熔金 | 橙 → 金 |
| 薄荷录音室 | 薄荷绿 → 天蓝 |

在「皮肤」面板里点卡片正文可以预览，点「应用」正式切换。皮肤同时驱动可视化配色与界面光晕，是整体换色而不是只换按钮颜色。

除了内置皮肤，也可以导入皮肤包目录，程序会校验 manifest 后再应用。

## 均衡器

十段均衡器，覆盖 `-12 dB` 到 `+12 dB`。内置四组预设：

| 预设 | 取向 |
| --- | --- |
| 平直 | 全部归零 |
| 摇滚 | 强化低频与高频 |
| 流行 | 中频略提 |
| 人声 | 突出中高频人声段 |

选中预设后仍可逐段微调，每段的增益值会实时显示。

## 歌词

- **歌词面板** —— 位于右侧「歌词」面板，按播放进度自动高亮当前行。
  面板里同时提供桌面歌词的主题、字号、锁定与鼠标穿透开关。
- **桌面歌词** —— 独立的置顶浮窗，背景完全透明，只显示歌词本身。
- **迷你播放器** —— 独立小窗，只保留封面、曲名与基础控制。

顶栏右侧的「迷你模式」与「桌面歌词」按钮分别打开这两个窗口。

### 桌面歌词

鼠标移到浮窗上会浮出一排工具条：

| 控件 | 作用 |
| --- | --- |
| 主题色板 | 极光 / 熔金 / 薄荷 / 水墨 / 糖果，五套配色 |
| 字号 | 0.6× – 2.4× 缩放 |
| 锁定 | 锁定后浮窗不再跟随鼠标拖动 |
| 鼠标穿透 | 点击穿透到浮窗下方的窗口 |
| 关闭 | 关闭桌面歌词 |

未锁定时**整个浮窗都是拖动区**，可以直接拖到桌面任意位置。
开启鼠标穿透后浮窗不再响应鼠标，此时锁定状态会以文字提示，避免窗口「找不回来」。

### 迷你模式

迷你模式是**替换**主窗口而不是叠加：打开时主窗口隐藏，关闭迷你窗口时主窗口自动回来，
屏幕上不会同时出现两个播放界面。

## 播放列表

- 支持文件与文件夹导入，文件夹会递归扫描。
- 当前曲目行有强调底色、动态音效条与「正在播放」标记。
- 曲目状态会直接标出来：文件丢失显示「文件丢失」，无法解码显示「不可播放」。
- 每行右侧显示时长，悬停时出现移除按钮。
- 左栏可以通过顶栏的「播放列表」按钮整体收起，把空间让给可视化。

## 标签编辑

「标签」面板可以修改当前曲目的标题、歌手与专辑，并写回文件。导入时程序会读取内嵌元数据，封面引用也会一并保留。

## 设置

「设置」面板提供：

- 播放/暂停与下一首的全局快捷键录入，冲突时会给出提示。
- 联网补全功能的开关状态。

设置会持久化到本地，重启后保持。
