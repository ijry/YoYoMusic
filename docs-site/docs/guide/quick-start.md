# 快速开始

打开悠悠乐听后，三步就能听到音乐。

## 1. 导入本地音乐

左上角「当前播放列表」面板里有两个按钮：

- **添加文件** —— 选择一个或多个音频文件。
- **添加文件夹** —— 递归扫描整个文件夹。

导入后曲目会立即出现在列表里，双击（或点击）任意一首即可开始播放。点击「清空」按钮可以移除整个列表。

::: tip 标签与封面
导入时程序会读取文件内嵌的标题、歌手、专辑与封面引用。信息缺失时，「标签」面板可以手动补全并写回文件。
:::

## 2. 播放与切歌

底部播放条从左到右依次是：

| 区域 | 内容 |
| --- | --- |
| 左侧 | 当前曲目的封面、标题与歌手 |
| 中间 | 上一首 / 播放暂停 / 下一首，以及带时间读数的进度条 |
| 右侧 | 静音、音量、播放模式 |

播放模式按钮会在四种模式间循环：**顺序播放 → 列表循环 → 单曲循环 → 随机播放**。一首放完会自动续播下一首。

## 3. 换一个可视化

中间的大区域就是可视化舞台。右上角有一排图标，点一下即可切换：

| 模式 | 特点 |
| --- | --- |
| 频谱柱 | 镜像频谱条，带峰值保持与倒影 |
| 示波波形 | 发光示波曲线，带刻度网格 |
| 环形律动 | 环形放射律动，中心随节拍脉动 |
| 音浪绸带 | 多层流动音浪绸带 |
| 粒子星尘 | 节拍驱动的粒子爆发 |
| 镜像瀑布 | 滚动频谱瀑布，左右对称 |

需要完整列表时，点右侧图标栏的「可视化」，面板里能看到每个模式的名称与说明。

## 界面布局

- **左栏** —— 播放列表。顶栏的「播放列表」按钮可以收起/展开。
- **中间** —— 可视化舞台。
- **右栏** —— 功能图标栏。默认收起，点图标展开对应面板，再点一次收起。
- **底部** —— 播放控制条。

## 常用快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl + Alt + P` | 播放 / 暂停 |
| `Ctrl + Alt + ←` | 上一首 |
| `Ctrl + Alt + →` | 下一首 |

快捷键在「设置」面板里可以修改。这些是全局快捷键，即使窗口不在前台也生效。
